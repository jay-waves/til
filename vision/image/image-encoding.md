## 图像编码分类

常见的图像编码格式汇总见 [ffmpeg](../ffmpeg.md)

## 图像压缩编码

* 有损压缩：不可逆压缩，一般存在量化步骤，体积显著小。
* 无损压缩：可逆压缩，可以还原所有原图像细节。

```
预测       ->  变换     -> 量化         -> 熵编码 (信息论)
Prediction -> Transform -> Quantization -> Entropy Coding
```

* 预测：用于去除时间、空间相关性
* 变换：去除频域相关性，集中能量
* 量化：实际产生有损压缩
* 熵编码：利用统计规律进一步压缩

### 熵编码


设图像灰度集为 $(W_{1},W_{2},\dots,W_{M})$, 概率分别为 $P_{1}, P_{2}, \dots, P_{M}$, 其自信息量为: 

$$I(W_{K})=-\log_{2}P_{k}(W_{K})$$

可以说，某个像素值出现的概率越小，其包含的信息量应越大。


*信息熵 (entropy)* 描述一个图像的不确定性，图像越接近完全均匀，其信息熵愈大：

$$H=\sum^{M}_{k=1}P_{K}(W_{k})\cdot I(W_{k})=-\sum^{M}_{k=1}P_{k}\log_{2}P_{k}$$


*条件熵* 是指，前一个像素已知后，后一个像素还包含多少不确定性。越平滑的图像，条件熵越小；
一般而言，相邻元素的条件熵也比间隔元素的条件熵小。

$$H\left( \frac{W_{i}}{W_{i-1}} \right)=-\sum^{M}_{k=1}\sum^{M}_{k=1}P(W_{i}, W_{i-1})\cdot \log_{2}P\left( \frac{W_{i}}{W_{i-1}} \right)$$

### 量化

$$e_n \to Q(e_n)$$

是指用有限的等级来表示误差数值，因此天然有失真。

### 预测

#### DPCM (插值脉冲编码调制)

不直接编码原像素 $x_n$ ，而是编码残差 (Residual) $e_n = x_n - \hat{x}_n$ 

其中： $\hat{x}_{n+1}=a_{1}x_{1}+a_{2}x_{2}+\dots a_{n}x_{n}$

原因是自然像素的临近像素相关性强，知晓前一个像素，后一个像素不确定性大幅减小：

\[
H(X_n|X_{n-1})\ll H(X_n)
\]

所以残差的熵更低，占用的信息更低（比特数更少）

### JPEG 格式

联合图像专家组 (Joint Photographic Experts Group, JPEG), 1993, 文件后缀为 `.jpg`

```
                            量化表          熵编码表
                              |               |
                              V               V
源图像数据   ->   图像变换  -> 　量化器   ->    熵编码器 -> 压缩后数据
(RGB -> YCbCr)     (DCT)    (Zigzag -> DC/AC)    (Huffman)
```

- 使用 $8\times 8$ DCT 变换
- 使用量化表对 64 个DCT 系数进行线性量化，对于每个 $8\times 8$ DCT 块：
    - 对于零频率分量 $F(0,0)$ ，称其为 DC (Direct Current)，代表了图像平均亮度（能量最大）
    - 对于非零频率 $F(i,j)$ ，称其为 AC (Alternative Current)，一般是纹理、边缘、细节，可以大量舍弃
    - DC 和 AC 的编码方式有区别
- 最后进行 Huffman 编码。
